# Math Notes

Personal notes, derivations, and worked word problems, written in Markdown
with real LaTeX math rendered by [KaTeX](https://katex.org/).

- Inline math: `$x^2 + y^2 = r^2$` renders as $x^2 + y^2 = r^2$.
- Display math: a `$$ ... $$` block renders centered on its own line.
- Word problems use a collapsible "Solution" block, so the problem can be
  read and attempted before revealing the answer.

See the [Blog](/blog/) for posts, or use the search bar above.
